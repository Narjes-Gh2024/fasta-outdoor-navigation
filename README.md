# Offroad Navigation

This repository contains software for a skid-steer offroad robot. It contains multiple parts:

1. simulation files (MuJoCo and Isaac Sim)
2. low-level FOC controller
3. high-level controller (with joystick or keyboard)
4. local state estimation
5. global state estimation and mapping
6. planning and autonomous navigation
